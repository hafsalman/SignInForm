# 🔐 Sign In Form App

A simple mobile Sign In Form built using **React Native with Expo**.  
This application demonstrates user input handling, form validation, and basic authentication UI design in a mobile environment.

---

## Features

- Email input field
- Password input field (secure entry)
- Basic form validation
- Error handling for empty/invalid inputs
- Clean and responsive UI

---

## Tech Stack

- React Native
- Expo
- JavaScript (ES6)
- Git & GitHub

---

## Installation & Setup

### 1️⃣ Clone the Repository

``` bash
git clone https://github.com/hafsalman/SignInForm
```

### 2️⃣ Initialize Expo Project 

``` bash
npx create-expo-app SignIn --template expo-template-blank
```

### 3️⃣ Navigate to Project Folder

``` bash
cd SignIn
```
(Replace the default App.js with the cloned App.js)

### 4️⃣ Start the Development Server

``` bash
npx expo start
```
